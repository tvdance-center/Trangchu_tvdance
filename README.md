# TV Dance Center — Public Website

Independent public-facing website for TV Dance Center. It introduces classes, dance styles, competitions, news, and contact channels. The existing CRM is not embedded or modified; CRM links open `https://crm.tvdance.online/` in a separate tab.

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```
